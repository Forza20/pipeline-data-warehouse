# pipeline-data-warehouse

English public version of the `/messy-pipeline` test bench. It builds a messy dataset, a medallion warehouse in Supabase, a Power BI report and a data catalog, and checks the numbers against the source.

## Map
- Use, setup and tests: `README.md`
- Business demo: `demo/business/README.md`
- Agents, commands and skills: `.claude/`
- Datasets: `datasets/` (see `datasets/README.md`)
- Report profiles: `profiles/`
- Runs: `runs/<run-id>/` (see `runs/CLAUDE.md`)
- Supabase migrations: `supabase/` (see `supabase/CLAUDE.md`)
- Scripts: `tools/` (see `tools/CLAUDE.md`)
- Licenses: `licenses/` (see `licenses/CLAUDE.md`)
- Settings: `pipeline.config.json` (template: `pipeline.config.example.json`)

A Danish working copy of this bench is kept separately. Fixes go to both.
