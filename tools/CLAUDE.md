# tools

Helper scripts. Run them from the repo root.

- `score.js`: scores a run against its answers (`node tools/score.js`).
- `sample-sql.js`: samples SQL output from the warehouse.
- `build-site.js` with `site-template.html`: builds the HTML result page.
- `dax-vault.py`, `update-vault.js`: write DAX measures to the Obsidian vault.
